1. As an administrator, open **Contacts → Configuration → Localization → Cities** and search
   for a postal code: the Moldovan localities of that postal code are listed with their district.

   ![Cities list filtered on the postal code MD-6501: the localities Anenii Noi, Beriozchi, Hirbovatul Nou, all of the state Anenii Noi (MD)](static/description/en/01_lista_localitati_cap.png)

2. Open a Moldovan contact and type the postal code in the address: the city and the region are
   filled in.

   ![Contact in Moldova: the postal code MD-3100 fills in the city Balti and the state Bălți (MD)](static/description/en/02_partener_cap_unic.png)

3. When the postal code is shared by several localities, only the region is filled in; choose the
   city from the list (type the postal code or the name in the city field).

   ![Contact in Moldova: the postal code MD-6501 fills in the state Anenii Noi (MD); the city field lists the localities of MD-6501](static/description/en/03_partener_cap_comun.png)

4. To complete existing or imported contacts, select them in the list and run
   *Actions → Moldova: set city from ZIP*.

   ![Contacts list with Moldovan contacts selected and the Actions menu open on Moldova: set city from ZIP](static/description/en/04_actiune_contacte_existente.png)

   ![Contact after the action: ZIP MD-6501, city Beriozchi (MD-6501) and state Anenii Noi (MD)](static/description/en/05_contact_dupa_actiune.png)
