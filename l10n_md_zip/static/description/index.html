Overview

Loads the Moldovan localities with their postal code and district, and fills in the city and the district of Moldovan addresses from the postal code.

  • Ships the list of Moldovan localities with their postal code, linked to the 37 subdivisions of the Republic of Moldova (ISO 3166-2:MD: the districts, the municipalities Chișinău, Bălți and Bender, Găgăuzia and Stînga Nistrului), which the module adds as states of Moldova. The data comes from GeoNames (Creative Commons Attribution 4.0).
  • Moldova is set to enforce cities: the city of a Moldovan address is chosen from the list.
  • On the contact form, typing the postal code (cod poștal) of a Moldovan address sets the city and the district. The postal code can be typed as MD-3100, MD3100 or 3100: when the locality is identified, it is written back as MD-3100. A postal code shared by several localities sets only the district, when they are all in the same district; the city name, when it matches one of them (without diacritics and case), picks the locality.
  • The action Moldova: set city from ZIP on contacts links the Moldovan contacts to the city of their postal code and fills in the district.
  • At install, the Moldovan contacts are linked: directly on a small database, by the scheduled action Moldova: link contacts to the city of their ZIP in batches on a large one (it deactivates itself when done).
Usage
  1. As an administrator, open Contacts → Configuration → Localization → Cities and search for a postal code, for example MD-6501: the Moldovan localities of that postal code are listed with their district in the State column.
1 Cities list filtered on the postal code MD-6501: Anenii Noi, Beriozchi and Hirbovatul Nou, all with the country Moldova and the state Anenii Noi (MD)
  1. Open a contact with the country Moldova and type the postal code in the address, for example MD-3100: the city and the state are filled in. The code can also be typed as 3100, MD3100 or md 3100; when the locality is identified, it is written back as MD-3100.
2 Contact Example Balti SRL in Moldova: the postal code MD-3100 fills in the city Balti (MD-3100) and the state Bălți (MD)
  1. When the postal code is shared by several localities (MD-6501), only the state is filled in (when the localities are all in the same district); choose the city from the list (type the postal code or the name in the City field). When the contact already has the city name, for example BERIOZCHI, that locality is chosen by itself (diacritics and letter case are ignored).
3 Contact Example Anenii Noi SRL: the postal code MD-6501 fills in the state Anenii Noi (MD); the City field lists Anenii Noi, Beriozchi and Hirbovatul Nou, all with MD-6501
  1. To complete existing or imported contacts, select them in the list view of Contacts and run Actions → Moldova: set city from ZIP (right Contact: Creation). Select the companies, not their contact persons: a contact person takes the address of its company. Contacts of other countries are left as they are.
4 Contacts list with 7 contacts selected and the Actions menu open; its last row is Moldova: set city from ZIP

After the action, a contact imported with the code 6501 and the city Beriozchi has the code MD-6501, the city Beriozchi and the state Anenii Noi.

5 Contact Customer Beriozchi after the action: ZIP MD-6501, city Beriozchi (MD-6501) and state Anenii Noi (MD)

At install, the Moldovan contacts that have a postal code are linked to their city: directly on a small database, or by the scheduled action Moldova: link contacts to the city of their ZIP, in batches, on a large one (it deactivates itself when done).

The names of the localities come from GeoNames without diacritics (Balti, Durlesti); the states have them (Bălți, Chișinău).
